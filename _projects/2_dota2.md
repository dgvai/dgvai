Data analysis research (2022), supervised by Md. Mehedi Hasan, RUET.

- Collected match data from 27,000 professional matches through OpenAPI.
- Designed a stacked bidirectional LSTM network to predict the winning team.
- Built a web application around the model for real-time winner prediction.

Presented at ICECTE 2022 {% cite uddin2022dota2 %}.
